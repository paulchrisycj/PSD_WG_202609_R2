The Problem

You are given an array of player objects from a small basketball league. Each object has a name, a team, a position, a points array of points scored per game, and a minutesPlayed average. Implement the functions described below.

Example done for you

getPlayerNames(players)
Returns an array of every player's name, in the same order as the input array.

Core Functions

getPlayerAverage(player)
Returns the average points per game for a single player. Return 0 if the array is empty.
💡 Tip: you will find this useful when writing the other functions.
getTeamAverage(players, team)
Returns the average points per game across all players on a team. Each player counts as one data point using their own average. Return 0 if no players match.
getTopScorer(players)
Returns the player object with the highest average points per game. Return null if the array is empty. If there is a tie, return the first one found.
getPositionGroup(players, position)
Returns a new array containing only players whose position matches the given value. The match is case-sensitive. Return an empty array if no players match.
getPlayerSummary(player)
Returns a formatted string: "<name> (<position>, <team>) — <avg> ppg", with the average rounded to one decimal place.

Stretch Goals optional

tagAllStars(players, threshold) stretch
Returns a new array where each player has an added allStar field (true/false) based on whether their average is at or above threshold. Do not modify the original objects.
getBenchWarmers(players, minAvg, minMinutes) stretch
Returns a new array of players who are considered "bench risks". A player is a bench risk if either of the following is true:
— their average points per game is below minAvg
— their minutesPlayed is below minMinutes
getTeamStandings(players) stretch
Returns a new array, one entry per team ({ team, average, rank }), sorted by team average descending. Teams with equal averages share the same rank — the next rank is skipped (e.g. two teams at rank 1 means the next is rank 3). Do not modify the original array or objects.
